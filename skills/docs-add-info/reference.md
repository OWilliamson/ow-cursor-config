## Reference templates

Use these as compact starting points when adding new information.

### Source registry row

| ID | Location | Title | Kind | Author ref | Site ref | Added | License / privacy | Notes |
|----|----------|-------|------|------------|----------|-------|--------------------|-------|
| SRC-### | exact URL or resource | short title | blog / repo / session / doc | AUT-### or - | SITE-### or - | YYYY-MM-DD | link only / internal notes / public | one-line note |

### Topic `reference.md`

```markdown
### Sources and quotations

> Short quote that explains a mechanism, constraint, or step. SRC-###

Context notes:

- Why this source matters to our Cursor config goals.
- What trade-off or design choice it implies.
```

### Topic `info.md`

```markdown
### Implementation notes

- Steps we would take to adopt this pattern in our hub.
- Where it would live: rules, skills, commands, templates, or docs.

### How it works

- Components involved and how they interact.

### Use cases for us

- When we should reach for this pattern.

### Possible improvements / deltas

- What this would improve in our current docs or tooling.
```
