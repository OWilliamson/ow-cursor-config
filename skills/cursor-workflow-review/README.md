# cursor-workflow-review (portable skill)

This folder is a **copy** of the canonical user skill for version control in this repository.

**Install for Cursor (personal skills):** copy the whole directory to:

`~/.cursor/skills/cursor-workflow-review/`

Canonical source in this repository: **`ow-cursor-config/skills/cursor-workflow-review/`**. Example:

```bash
cp -a /path/to/ow-cursor-config/skills/cursor-workflow-review/ "$HOME/.cursor/skills/cursor-workflow-review/"
```

Then Cursor can load `SKILL.md` from that path.

**Two-way sync:** if you maintain a copy under `~/.cursor/skills/cursor-workflow-review/`, copy back into `ow-cursor-config/skills/cursor-workflow-review/` before committing, or run the reverse `cp -a` after editing in-repo.
