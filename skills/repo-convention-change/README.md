# repo-convention-change (personal skill)

Defines a **repository-agnostic** workflow for **new**, **restatement**, or **redefinition** of repo-wide conventions—so “we already decided this” is handled as **drift closure**, not a silent new policy.

**Install (Cursor):** keep this folder at:

`~/.cursor/skills/repo-convention-change/`

Cursor loads `SKILL.md` by skill name **`repo-convention-change`**. Say in chat: *“Follow the **repo-convention-change** skill.”*

**Team / single repo:** copy the directory into `<repo>/.cursor/skills/repo-convention-change/` and add one line to `AGENTS.md` pointing agents at the skill when changing policy.

**Refresh:** after editing here, copy to other machines or in-repo copies as needed.

**Pairing:** use the repo **`AGENTS.md` → Tooling profile** when the convention touches scripts or generated artifacts; use **`cursor-workflow-review`** for a full handbook/rules audit.
