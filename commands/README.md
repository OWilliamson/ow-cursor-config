# Cursor slash commands (`commands/`)

Commit/PR workflows are covered by user rules and [`github-and-remotes.mdc`](../rules/github-and-remotes.mdc). Security review: Cursor `/review-security` skill. Project domain commands remain in [`project-specific/`](../../project-specific/) bundles only.

Recover a retired command from `archive/superseded-commands/<name>/<timestamp>/`, copy back to `private/commands/` or `public/commands/`, update [`config-classification.yaml`](../../config-classification.yaml), then run `scripts/sync-cursor.sh reconcile`.
